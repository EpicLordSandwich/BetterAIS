# BetterAIS

Browser extension (Chrome/Firefox, MV3) pre STU UIS (is.stuba.sk). Vylepšuje vzhľad, ovládanie a používateľský komfort UIS: témy, tmavý/svetlý režim, CSS snippety, paleta príkazov (Ctrl+K), table-tools, vlastné odkazy, notifikácie pošty, dashboard hodnotení (E-index).

Runtime je v priečinku `BetterAIS_beta/`. Inštalácia, použitie a dokumentácia sú v `BetterAIS_beta/README.md`.

## Témy
Claude, Sleek, Nord, Bloom, Comfy, Catppuccin, Dracula, Gruvbox, STU modrá, OLED, OG AIS, Nothing, Techy, Clean (+ importované vlastné).

## Vývoj
```bash
cd BetterAIS_beta
npm test
node --check *.js
```
